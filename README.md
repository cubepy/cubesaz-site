# کیوب‌ساز

پلتفرم فروش خودکار سرویس با ربات تلگرام.

با کیوب‌ساز، ربات فروش، پنل مدیریت و اپلیکیشن اختصاصی خودتان را در چند دقیقه
می‌سازید — بدون نیاز به سرور، برنامه‌نویسی یا دانش فنی.

## چه چیزی به شما می‌دهد

- **ربات فروش اختصاصی** — مشتری‌هایتان مستقیم از داخل تلگرام خرید می‌کنند
- **پنل مدیریت تحت وب** — کاربران، سرویس‌ها، قیمت‌ها، تخفیف‌ها و گزارش مالی
- **اپلیکیشن داخل تلگرام** — فروشگاه و صفحه‌ی حساب کاربری برای مشتری
- **پرداخت خودکار** — درگاه‌های ریالی، رمزارز، کارت‌به‌کارت و کیف پول
- **تمدید و یادآوری خودکار** — بدون دخالت شما
- **سیستم نمایندگی و معرفی** — با پورسانت و سطح‌بندی قیمت
