# کیوب‌ساز

**ربات آماده فروش VPN در تلگرام.**

بدون هاست، بدون سرور، بدون دانش فنی — برای کسانی که آماده‌اند فروش‌شان را
خودکار کنند.

پنل‌های خودتان را وصل می‌کنید، قیمت می‌گذارید، و ربات بقیه‌اش را انجام می‌دهد:
فروش، تحویل، تمدید، یادآوری و پشتیبانی — شبانه‌روز، بدون دخالت شما.

## چه چیزی تحویل می‌گیرید

- **ربات فروش اختصاصی خودتان** — مشتری مستقیم از داخل تلگرام می‌خرد
- **پنل مدیریت تحت وب** — کاربران، سرویس‌ها، قیمت‌ها، تخفیف‌ها و گزارش مالی
- **اپلیکیشن داخل تلگرام** — فروشگاه و کارت اشتراک برای مشتری
- **پرداخت خودکار** — کارت‌به‌کارت با تأیید آنی پیامکی، درگاه ریالی، رمزارز، استارز و کیف پول
- **تحویل و تمدید خودکار** — بدون دخالت دستی
- **سیستم نمایندگی و معرفی** — با پورسانت و سطح‌بندی قیمت

روی مرزبان، ثنایی (x-ui)، هیدیفای، مرزنشین، IBSng، Mikrotik، WGDashboard و
علیرضا کار می‌کند — هم‌زمان.

**۱۴۷ قابلیت آماده و فعال.** [فهرست کامل](https://cubepy.github.io/cubesaz-site/#features)
